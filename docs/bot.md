# Бот Telegram «Опора» с проверкой подписки на канал

## Как это работает
- Человек пишет боту `/start`. Если он подписан на канал, бот присылает кнопку «Открыть карту» (мини-приложение `/tg`). Если нет, просит подписаться: кнопки «Подписаться на канал», «Я подписался — проверить» и «🚨 Срочно — без подписки».
- Мини-приложение `/tg` само ещё раз проверяет подписку на сервере (подпись `initData` + `getChatMember`) и только потом открывает карту.
- **Режим «Тревога» (`/alarm`) открывается без подписки всегда.** Обычный сайт `oporamap.ru` остаётся открытым для всех, гейт действует только на вход через бота.
- Если проверить подписку не удалось (бот не администратор канала, сбой Telegram), человека пускают, и в админке на вкладке «Бот» появится красная строка.

## Что нужно сделать
1. **Создать бота:** в Telegram написать @BotFather → `/newbot` → имя и username (например `opora_map_bot`). Получить токен.
2. **Создать канал** (или взять существующий) и **добавить бота администратором канала** (право читать подписчиков обязательно).
3. **Переменные в Vercel** (все описаны в `.env.example`) и Redeploy:
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather
   - `NEXT_PUBLIC_TELEGRAM_BOT` — username бота без @
   - `TELEGRAM_CHANNEL` — `@имя_канала` (или числовой id `-100…`)
   - `TELEGRAM_CHANNEL_LINK` — ссылка на канал (нужна для приватного канала)
   - `TELEGRAM_WEBHOOK_SECRET` — любая строка из латинских букв, цифр, `_` и `-`
4. **Админка → вкладка «Бот» → «Установить бота».** Она ставит вебхук, команды, кнопку меню и описание. Все строки состояния должны стать «ок».
5. **Войти через Telegram в чате:** в BotFather команда `/setdomain` → выбрать бота → указать домен сайта (`oporamap.ru`).
6. Проверить: открыть бота в Telegram, `/start`.

## Отключение
- Убрать `TELEGRAM_CHANNEL`: проверка подписки выключится, карта будет открываться всем.
- `TELEGRAM_URGENT_BUTTON=0`: убрать кнопки «Срочно» (не рекомендую: тревожный режим должен быть доступен всем).
- Вкладка «Бот» → «Снять вебхук»: бот перестанет отвечать.

## MAX
Бот и мини-приложение MAX делаются отдельно: им нужен верифицированный профиль (самозанятый, ИП или организация-резидент РФ) и свои правила. Вход в чат внутри мини-приложения MAX уже поддержан (`MAX_BOT_TOKEN`).

## Юридически
- Требовать подписку на канал для открытия мини-приложения законом не запрещено, но на странице входа и в посте канала нужно честно писать, что подписка нужна для открытия карты, а режим «Тревога» открыт всем.
- Подписчики канала — отдельная аудитория: если в канале будет реклама, действуют правила маркировки (ЕРИР).
